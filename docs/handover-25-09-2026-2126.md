## Key findings (don't re-derive these)

1. Telablur's blockiness/grid noise is **inherent to the encode/measure roundtrip**, not a blending artifact — confirmed via self-test with image1=image2 (set 07).
2. Three independent, composable levers: **mask** (spatial), **direction** (noise character: full=grid, vertical/horizontal=streakier), **strength** (how much of image2 shows through).
3. **Winning mask config so far: `mask.distance_gradient(alpha, radius=30)` + `strength=0.1` + `direction=full`** (set 13, confirmed by Bogdan as best of 15 combos). Use this as the default going forward unless a new test beats it.
4. A person/background mask lets a subject survive recursion untouched while the background is driven through arbitrary photos (set 05).
5. Progressive dilation of the mask each recursion round ("eating" the subject) works and reaches a strong effect by round 5 at `DILATE_STEP=15` — confirmed acceptable by Bogdan (set 15), though "it has eaten a lot."
6. `coin-toss-v1` is JSON-only (no file inputs), 2 credits/run, ~7-10s regardless of `shots`. Use `shots=1` per bit for genuine fair coin flips — don't use high shots + heads/tails ratio for a continuous random value, the ratio concentrates near 0.5 (binomial), not uniform.
7. Full engine catalog (9 real + 1 conditional): `telablur-v1`, `blur-v1`, `blur-core-v1`, `tessa-image-v1`, `deep-fryer-v1`, `entanglement-shader-v1`, `qrc-audio-v1`, `retrocausal-echo-v1`, `otoc-echo-v1`, `qpixl-v1`, plus `blur-midi-v1`. Only `telablur-v1` and `coin-toss-v1` used so far.
